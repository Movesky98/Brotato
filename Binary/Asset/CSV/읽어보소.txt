주요 항목
1. InventoryComponent::mStat 연결
	현재 InventoryComponent에서 각 UI로 현재 Stat 상태를 업데이트하는 로직은 구현되어 있음.
	남은 건 현재 스탯을 바탕으로 무기, 캐릭터의 상태를 맞춰줘야 함.

2. 시작 무기 구현 (완료)
	CharacterDesc.csv에 필드 추가 (StartWeaponID)
	CSV -> F* 구조체 -> C* 데이터 에셋 클래스 구조를 통해 캐릭터마다 시작 무기를 들고 시작하도록 구현할 것.
	이 구조가 된다면 재화를 이용한 상점 이용 시스템의 구현이 가능함.

3. 캐릭터 선택 창 (CharacterSelectScreen) 캐릭터 스탯 및 시작 무기 필드 업데이트 (완료)
	2번이 끝나면 3번을 할 수 있음.
	시작 무기도 있고, 스탯도 있으니 필드에 업데이트만 하면 됨.
	다만, 지금 StatPanel에만 있는 NAME to Primary/Secondary Stat 매핑 구조를 여기서도 쓸 수 있도록 해야 함.

4. 상점 시스템 구현 (완료)
	현재는 상점 UI만 구현되어 있으며 기능적으로는 무기 구매 시 플레이어 인벤토리에 저장되는 것만 되어 있음.
	상점의 근본인 재화를 이용한 구매, 불가, 잠금, 차단 등을 만들어 볼 것.

5. 보스 구현
	Brotato의 보스 구현

6. 사망 애니메이션 및 플레이어 이동 시 애니메이션 구현
	내가 보기엔 보스보다 이게 더 급할 것 같긴 한데.

7. 몬스터 등장 순서 CSV
	위가 다 만족되면 웨이브 마다 들어갈 몬스터를 저장하는 WaveDesc.csv가 있으면 좋을 것 같음.
